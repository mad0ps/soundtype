# SoundType

Офлайн-диктовка для Ubuntu Touch. Говоришь — получаешь текст напрямую в поле ввода через системную клавиатуру!

Распознавание целиком на телефоне: ни одного байта наружу, ни облаков, ни ключей, ни интернета. Работает в самолётном режиме.

**Статус:** рабочая версия 0.8.0 для Ubuntu Touch 24.04 (noble); для UT 20.04 — [релиз 0.6.0](https://github.com/mad0ps/soundtype/releases/tag/v0.6.0).

> Это сокращённая русская версия. Полная документация (разработка,
> архитектура, известные ограничения) — в [английском README](README.md).

## Как пользоваться

### Системная клавиатура (рекомендуемый способ)

1. **Зажми пробел** (~0.8 с), не двигая палец — короткая вибрация скажет
   «принято». Отпусти — пошла запись: индикатор на пробеле оживает,
   распознанные фразы **печатаются в поле прямо по ходу речи**.
2. **Короткий тап по пробелу** — стоп (пробел не печатается). Жёлтый
   микрофон = дорасшифровывается хвост.
3. Кнопка микрофона в свайп-меню (свайп вверх по клавиатуре) делает то же.

Цвета микрофона: **серый** — движок не в памяти (первый старт ~5 с),
**жёлтый** — грузится/расшифровывает, **красный пульс** — запись,
**зелёный** — готов мгновенно. После 5 минут простоя движок выгружается сам.

Стоковый тачпад на месте: зажал пробел и **повёл палец** — курсор.

### Приложение

Зелёная кнопка — запись, красная — стоп, текст в буфере обмена. История
расшифровок с повтором распознавания — внутри приложения.

## Установка

```sh
git clone https://github.com/mad0ps/soundtype.git
cd soundtype
./scripts/build.sh && ./scripts/install.sh
```

Модель (~500 МБ) приложение скачает само при первом запуске (лучше по Wi-Fi).

Интеграция в клавиатуру (патчит системный раздел, слетает при OTA —
просто перезапусти скрипт):

```sh
sudo bash extras/keyboard-integration/install.sh
```

Откат: `sudo bash extras/keyboard-integration/uninstall.sh`.

## Требования

Ubuntu Touch 24.04 (noble), arm64 · ~1.5 ГБ на диске · компилятор не нужен.
