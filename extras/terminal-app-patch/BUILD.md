# Сборка терминала с починенным выделением и кнопкой диктовки

Что чиним и добавляем:

1. **Выделение не работает поверх TUI-приложений** (`vim`, `htop`, `tmux`,
   Claude Code). Пока программа просит передавать ей события мыши, терминал
   не делает собственного выделения — протяжка уходит программе. Пункт
   `Copy` из-за этого всегда неактивен.
2. **Падение при выходе из режима выделения** — исправлено в апстриме
   (MR !126, слит 31.08.2026, есть в `main`; в выпуске 2.0.6 его ещё нет).
   Отдельный патч больше не нужен: `fix-selection-mode-use-after-free.patch`
   оставлен для истории, не применять.
3. **Кнопка диктовки SoundType** рядом с круглыми «клавиатура» и «Enter»
   (патч 0003). Тап — старт/стоп; красная — запись, жёлтая — распознавание.
   Терминал включает запись своей командой службы (`ToggleAppDictation`),
   итог приходит только ему (`AppTranscriptionReady`), и он вставляет текст
   сам — открыта клавиатура или нет; клавиатура получает пустой итог и
   ничего не вставляет. Кто остановил запись, тот и вставляет текст.
   Круглый Enter во время записи = стоп + текст + Enter. Нужна служба
   SoundType с `ToggleAppDictation` и модуль
   `~/soundtype/py/soundtype_app_bridge.py`; нет модуля — кнопки нет.

Патч 0004 — личные настройки (кнопка `@paste` из раскладки Termius и
долгое нажатие 200 мс вместо апстримных 400), применять по желанию.

Первое требует правки нативной библиотеки, поэтому нужен компьютер: на
телефоне нет компилятора и поставить его некуда — корень только для чтения.

## Что нужно на ноутбуке

* Docker (`clickable` собирает внутри контейнера, ничего в систему не ставит)
* Python 3
* Телефон, подключённый по USB, с включённым режимом разработчика

```sh
pipx install clickable-ut     # или: pip install --user clickable-ut
clickable --version
```

## Сборка

```sh
git clone --recurse-submodules \
  https://gitlab.com/ubports/development/apps/lomiri-terminal-app.git
cd lomiri-terminal-app

# правки лежат в extras/terminal-app-patch/ репозитория soundtype
P=/путь/к/soundtype/extras/terminal-app-patch
git apply --directory=libs/qmltermwidget $P/0001-qmltermwidget-writable-terminalUsesMouse.patch
git apply $P/0002-terminal-app-selection-over-tui.patch
git apply $P/0003-terminal-app-dictation-button.patch
git apply $P/0004-personal-paste-and-interval.patch   # по желанию

# В контейнере clickable репозиторий принадлежит другому uid, и git
# отказывается с ним работать. Локально (не в апстрим) добавить в
# clickable.yaml, в prebuild библиотеки qmltermwidget, первой строкой:
#   - git config --global --add safe.directory '*' || true

# Версия ОБЯЗАТЕЛЬНО выше предустановленной: при той же версии (2.0.6)
# сервис click молча оставляет системный терминал, и сборка не ставится.
sed -i '' 's/VERSION 2.0.6 /VERSION 2.0.6.1 /' CMakeLists.txt   # macOS sed

# --all: собрать и библиотеку qmltermwidget, и приложение
# (без него упаковка падает: нет QMLTermWidget/qmldir)
clickable build --all --arch arm64
```

Не проверено: когда UBports выпустит 2.0.7, предустановленная версия станет
выше нашей; что тогда выберет click — проверить после такого обновления
(`click pkgdir terminal.ubports`) и при необходимости пересобрать поверх
нового апстрима.

Собранный `.click` появится в `build/arm64-linux-gnu/app/`.

## Установка на телефон

Через USB, если телефон подключён:

```sh
clickable install --arch arm64
```

Либо скопировать `.click` на телефон и поставить там **без root** —
`pkcon` для click-пакетов не годится (бэкенд PackageKit здесь `aptcc`, он
только про `.deb`), нужен привилегированный сервис:

```sh
gdbus call --system --dest com.lomiri.click \
  --object-path /com/lomiri/click \
  --method com.lomiri.click.Install ~/имя-пакета.click
```

## Что проверить после установки

| Сценарий | Ожидание |
|---|---|
| Выделение + нижняя плашка в чистой вкладке, 5 раз подряд | не падает, копируется |
| То же под `htop` | **теперь копируется** — это и есть суть правки |
| То же под Claude Code | копируется |
| Попап через кнопку в шапке | открывается, пункты активны |
| Попап долгим тапом | открывается, пункты активны |
| Закрыть и открыть приложение | без неожиданностей |
| `journalctl -f` во время всего этого | ни одного `TypeError` |
| Клавиатура спрятана: микрофон → фраза → микрофон | текст появился ровно один раз |
| `journalctl --user` после этого | одна строка `SoundType: inserting`, через миллисекунды после `Event: done` службы |
| Клавиатура открыта: диктовка пробелом | текст ровно один раз, в журнале терминала нет `inserting` |
| Круглый Enter без диктовки | обычный Enter |
| Круглый Enter во время записи | текст вставлен и сразу отправлен |

Отдельно: `SIGABRT` при закрытии приложения к этим правкам отношения не
имеет, это давний отдельный дефект. Не спутать.

## Чего эти правки НЕ чинят

`QMLTermWidget` не поддерживает **OSC 52** — управляющую последовательность,
которой консольные программы кладут текст в системный буфер. Поэтому
автокопирование при выделении внутри самих программ (Claude Code и подобных)
по-прежнему уходит в никуда: программа считает, что скопировала, буфер
остаётся пустым. Это отдельная задача в той же библиотеке.
