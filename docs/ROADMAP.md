# SoundType — Roadmap (сведение экспертного совета 2026-08-21)

Синтез шести независимых отчётов: ресёрчи (silero-VAD практика, Parakeet P&C,
реверс Spokenly) + эксперты (архитектор, ASR/ML, UX мобильного Linux).
Полные отчёты — в сессионных логах; здесь — план действий.

## Ключевые открытия совета

1. **OpenStore принимает unconfined-FOSS через ручное ревью** (прецеденты:
   UT Tweak Tool, Waydroid Helper). Идея «кнопка установки интеграции в
   приложении с PIN-попапом» — принятый на UT паттерн (QProcess `sudo -S`).
2. **Hotwords уже в нашей sherpa-onnx 1.13.6** (PR #3077, TDT поддержан):
   кастомный словарь терминов = конфиг, не апгрейд. Цена: beam search
   роняет RTFx в 2-4 раза — сначала замер.
3. **Зафиксировать язык у Parakeet v3 нельзя в принципе** (NVIDIA issue
   закрыт) — против «сваливания в английский» работают длинные сегменты
   (сделано в 08b5204), hotwords и пост-замены.
4. **Пути из /etc/system-image/writable-paths переживают OTA** — фундамент
   для авто-восстановления патча клавиатуры.
5. **Upstream реален**: lomiri-keyboard жив (релиз 18.08.2026), voice-тем в
   трекере нет, спрос задокументирован (автор SOTY просил интеграцию).
   Выигрышная форма — нейтральный D-Bus «dictation provider», не «SoundType
   в апстрим». Оба эксперта пришли к этому независимо.
6. **Наш стриминг глубже эталона**: локальные модели Spokenly вставляют
   текст только после отпускания кнопки. Стриминг — киллер-фича, но ей нужен
   «пакет доверия» (undo, preedit).
7. **silero_te без официального ONNX** (только torch.package) → R&D-экспорт
   на десктопе прежде интеграции. Альтернатива/дополнение: GigaAM-v3 e2e
   (SOTA чистый русский, встроенная пунктуация+нормализация, конверсии под
   sherpa на HF) как переключаемый профиль.

## Фазы

### Фаза 1 — «Доверие к стримингу» (наш код, без миграций)
- [ ] **Undo последней фразы**: кнопка/жест, откатывающий последний
      закоммиченный сегмент backspace-ами (длину знаем). Снимает главный
      страх стриминга. (M)
- [ ] **Smart spacing**: пробел/регистр по surrounding text при вставке в
      середину текста, после знаков, после эмодзи. (S)
- [ ] **Password/URL-поля**: в `ImhHiddenText` диктовку выключать
      принудительно; в url/search — режим без глюков. Бонус: аргумент
      безопасности для ревью OpenStore. (S)
- [ ] «Новая строка» голосом + inhibit гашения экрана при записи. (S)

### Фаза 2 — «Качество» (по одному изменению за раз)
- [ ] **Eval-харнесс СНАЧАЛА**: корпус 20-30 реальных диктовок (ru + микс),
      эталоны, скрипт WER/CER + terms accuracy. Умножает всё остальное. (S)
- [ ] **Hotwords + modified_beam_search**: замер RTFx на N10 → включение
      (возможно только при низком confidence по ys_log_probs). (M)
- [ ] **Модуль пост-замен**: глоссарий транслита («депло→deploy») +
      «добавить замену» тапом из истории; регистронезависимость через
      casefold, кириллические границы слов. (S-M)
- [ ] **Ёфикатор**: Parakeet не знает «ё» (корпуса без неё) — словарный
      проход по однозначным словам (еще→ещё, зеленый→зелёный), омографы
      (все/всё) не трогаем; готовые словари в опенсорсе (yoficator). (S)
- [ ] AGC/gain перед VAD (тихий микрофон роняет и VAD, и ASR). (S)
- [ ] R&D: экспорт silero_te в ONNX на десктопе; профиль «чистый русский»
      на GigaAM-v3 e2e; GTCRN denoise тумблером. (L, по очереди)
- [ ] v1.2 overlap+LCS на стыках — после харнесса, чтобы мерить эффект. (M)

### Фаза 3 — «Архитектура» (порядок архитектора: API → шим → движок → OTA)
- [ ] **D-Bus API `org.soundtype.Engine1`**: версионированный контракт
      (StartSession/StopSession/GetState + сигналы). Бесплатно даёт CLI. (S)
- [ ] **Loader-шим**: патч клавиатуры сжимается до Loader + хуки SpaceKey;
      вся логика в ~/.soundtype/kbd/ — обновления без root, OTA почти не
      страшен. (M)
- [ ] **Единый движок**: приложение = D-Bus-клиент демона (минус вторая
      копия ~1ГБ, один аудиопуть). Требует unconfined (фаза 4). (M)
- [ ] **OTA-выживание**: user-unit сверяет hash системных файлов на boot →
      нотификация → «восстановить одной кнопкой»; уровень C (автомат через
      writable-paths) — после проверки на устройстве, со строгой
      самопроверкой (root-owned, immutable, hash-манифест). (M)
- [ ] Preedit вместо посимвольного commit (Maliit composing text):
      партиалы — подчёркнутый черновик, commit по финалу; посимвольный
      режим остаётся fallback-настройкой. (M)

### Фаза 4 — «Люди» (дистрибуция)
- [ ] **Unconfined + установщик интеграции в приложении** (паттерн UT Tweak
      Tool: экран «что изменится» → PIN → патч → done). (M)
- [ ] **OpenStore**: заявка через TG-группу админов (репо + build +
      обоснование привилегий); стор-страница продаёт confined-ценность
      (буфер+история), интеграция — опциональный мастер внутри. «Local
      Only / работает в самолётном режиме» — первый абзац. (M)
- [ ] Онбординг загрузки: warning на сотовых, resume, индикатор места. (S-M)
- [ ] Анонс на forums.ubports.com: «первая клавиатурная диктовка на UT». (S)

### Фаза 5 — «Стратегия»
- [ ] **RFC в lomiri-keyboard**: issue + Matrix — generic D-Bus dictation
      provider (кнопка-микрофон + тонкий клиент в клавиатуре, провайдер
      любой; SOTY — союзник). Наши патчи — работающий прототип и мост до
      мержа. (M предложить / L доземлить)
- [ ] Звонок/BT-маршруты: автостоп при входящем, источник по умолчанию =
      микрофон телефона (SCO 8/16кГц портит распознавание). (M)
- [ ] Конвергенция: тумблер диктовки в индикаторе верхней панели (hold-space
      физически недоступен при hw-клавиатуре, oskEnabled=false). (S)

### Не делаем (решение совета)
- Полный spoken-punctuation набор (модель пунктуирует сама; омонимия);
  double-tap активация (нет запроса); re-dictate фразы (v2+);
  облачные движки/BYOK (против позиционирования).
